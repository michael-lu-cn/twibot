# 迭代总结：书签完善 + URL 路由 + 外链跳转

日期：2026-08-29

## 一、背景与目标

本轮迭代围绕书签页与全局导航展开，共 4 个需求：

1. **书签加载不完整** —— 只能看到本地一小部分书签，同步也抓不全。
2. **书签按月分组** —— 列表按推文创建时间分月展示。
3. **右侧隐藏月份导航** —— 右侧一列细横杆（每根代表一个月），悬停展开按月目录栏，月份多时可滚动。
4. **左侧导航与 URL 对应** —— 切换页面 URL 同步变化，支持直达与前进/后退。
5. **用户/推文跳转原网址** —— 任意用户、任意推文可一键打开 X（Twitter）原页面。

## 三、实现要点

### 1. 书签加载完整
- **根因**：前端读接口只取 100 条（后端上限 500）；同步接口上限 200 且滚动仅 5 轮，X 书签页每轮约 20 条，抓不全。
- **修复**：读接口默认拉全量（后端上限 5000）；同步上限提到 2000，并新增书签专用滚动轮数 `bookmarkScrolls`（默认 30），滚动到无新推文自动停止，一次尽量同步完整。

### 2. 按月分组
- 按推文**创建时间**降序分月（如「2026年8月」），每组带「N 条」统计。
- 无法解析时间的推文归入末尾「时间未知」组。
- 以 `Date.parse` 解析 X 的 RFC 2822 时间格式，纯前端分组排序（SQL 对文本格式排序不正确，故不在后端做）。

### 3. 右侧隐藏月份导航
- 固定在视口右缘垂直居中；默认只显示**一列细横杆**（每根 = 一个月份，按时间降序与内容一致）。
- 悬停整列：左侧弹出「按月导航」面板（月份 + 条数），点击任意项平滑滚动跳转。
- 点击单根横杆：直达对应月份。
- 月份多时：横杆列与面板均限制最大高度、内部细滚动条滚动。
- 无书签数据时整条导航隐藏。

### 4. 左侧导航与 URL 对应
- 采用 **hash 路由**（`#/home`、`#/following`、`#/groups`、`#/bookmarks`、`#/auth`、`#/users/<handle>`）——静态托管/直接打开 dist 也不会 404，兼容性最好。
- 点击导航 ↔ URL 双向同步；`hashchange` 监听支持浏览器前进/后退。
- 从任意页进入用户主页后，左侧高亮来源页签，「返回」回到进入前的页面。

### 5. 用户/推文跳转原网址
- 所有推文卡片（主页/书签/用户主页复用 `TweetCard`）：作者行右侧 ⤴ 打开 `https://x.com/<handle>`；互动行右侧 ⤴ 打开原推文 `t.url`。
- 关注列表、智能分组每个用户行尾 ⤴ 打开原用户主页（`stopPropagation`，不触发整行应用内跳转）。
- 用户主页顶栏 ⤴ 打开该用户 X 主页。
- 全部 `target="_blank"` + `rel="noopener noreferrer"`；应用内「用户主页」功能保留，两入口并存。

## 四、验证情况

- `apps/web`：`tsc -b` 与 `vite build` 全部通过，dist 已重新构建。
- 月份分组纯函数用 X 真实时间格式单测通过（跨月降序、未知时间兜底正确）。
- 注意：`apps/api` 的 `typecheck` 脚本**原本就不可用**（该包无 tsconfig，`tsc --noEmit` 只输出帮助即失败），与本次改动无关；sync-feed 残留类型报错均来自 workspace 依赖（cordis 源码严格模式下编译、playwright 未装类型），非本轮代码引入。

## 五、使用说明

1. 访问 Web（dev 或 dist 静态预览）后 **强制刷新**（Ctrl/Cmd+Shift+R）加载新构建产物。
2. 「书签」页点「同步」→ 一次拉取尽量完整的书签，自动按月分组展示。
3. 右侧横杆悬停/点击快速跳转月份。
4. 地址栏可直达：`#/bookmarks`、`#/groups`、`#/users/<handle>` 等。
5. 任何用户/推文旁的小外链图标 ⤴ 在新标签打开 X 原页面。

## 六、遗留与建议

- `apps/api` 无 tsconfig，typecheck 脚本为无效占位，建议后续补一个项目级 tsconfig（可纳入根 `tsc -b` 引用）。
- 书签同步为手动触发；若书签量极大（>2000 条），同步耗时较长，可考虑分页增量同步。
- hash 路由对分享/收藏友好；如需"干净路径"式 URL（无 `#`），需部署端配置 SPA fallback，暂不建议。
